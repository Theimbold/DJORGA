# Task 052: Bitmap Value Converter

## Feature
Visual Arts (Covers)

## Aufgabe
Implementierung eines XAML-Konverters, der den gespeicherten Dateipfad des Covers in ein für Avalonia anzeigbares Bitmap-Objekt lädt.

## Schritte
1. Erstellen der Klasse `BitmapAssetValueConverter` in `MyApp.Desktop.Converters`.
2. Implementierung der `IValueConverter` Schnittstelle.
3. Hinzufügen von Fehlerbehandlung (Standard-Icon, falls Pfad ungültig).

## Definition of Done
- Konverter wandelt Strings erfolgreich in Bitmaps um.
- Bilder werden performant geladen.
