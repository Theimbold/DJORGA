# Task 021: Sidebar Navigation UI

## Feature
The Shell Layout

## Aufgabe
Gestaltung einer modernen Sidebar nach den Corporate Design Vorgaben für DJORGA.

## Schritte
1. Erstellung des `SidebarView` UserControls.
2. Definition der Navigations-Items (Dashboard, Library, AI-Builder, Settings).
3. Styling der Items: 
   - Transparenter Hintergrund.
   - Weißer Schatten bei Auswahl (Active State).
   - Sanfter Glow bei Hover.
4. Einbindung in das `MainWindow`.

## Definition of Done
- Sidebar ist links im MainWindow fixiert.
- Klick auf Items löst (vorerst logisch) den Seitenwechsel aus.
- Visuelles Feedback bei Hover und Selektion entspricht den UX-Vorgaben.
