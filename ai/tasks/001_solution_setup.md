# Task 001: .NET 8 Solution & Project Setup

## Feature
Solution Setup

## Aufgabe
Erstellen einer neuen .NET 8 Solution und Initialisierung der Kern-Projekte für die Clean Architecture Struktur.

## Schritte
1. Erstellen der Solution-Datei `DJORGA_New.sln` (Umbenennung später nach Validierung).
2. Erstellen des Projekts `MyApp.Domain` (Class Library, .NET 8).
3. Erstellen des Projekts `MyApp.Application` (Class Library, .NET 8).
4. Erstellen des Projekts `MyApp.Infrastructure` (Class Library, .NET 8).
5. Erstellen des Projekts `MyApp.Desktop` (Avalonia App Template, .NET 8).
6. Hinzufügen aller Projekte zur Solution.

## Definition of Done
- Alle Projekte sind erfolgreich erstellt und auf .NET 8 ausgerichtet.
- Die Solution lässt sich ohne Fehler laden.
- Keine Code-Inhalte außer Standard-Templates vorhanden.
