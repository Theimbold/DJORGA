# Task 003: Core Entitäten Implementierung

## Feature
Domänen-Modell Migration

## Aufgabe
Implementierung der zentralen Geschäfts-Entitäten im `MyApp.Domain` Projekt basierend auf der Informationsarchitektur.

## Schritte
1. Erstellen der Klasse `Track` in `MyApp.Domain/Entities`.
2. Erstellen der Klasse `Playlist` in `MyApp.Domain/Entities`.
3. Implementierung der Properties (Id, Title, Artist, Bpm, Key, etc.).
4. Hinzufügen von Konstruktoren und grundlegender Validierungslogik (z.B. Bpm > 0).

## Definition of Done
- `Track` und `Playlist` Klassen sind implementiert.
- Alle Felder aus der Design-Phase (Phase 2) sind enthalten.
- Code folgt C# Coding Standards (PascalCase, XML-Kommentare).
- Projekt `MyApp.Domain` kompiliert fehlerfrei.
