# Abhängigkeiten (IST-Zustand)

## Externe Abhängigkeiten (NuGet)
Das Projekt `RekordboxAi.csproj` nutzt folgende Pakete:
- `Avalonia` (11.0.0)
- `Avalonia.Desktop` (11.0.0)
- `Avalonia.ReactiveUI` (11.0.0)

## System-Abhängigkeiten
- **Windows OS:** Das Projekt `RekordboxAi` ist aktuell auf `net6.0-windows` ausgerichtet.
- **.NET Framework 4.7.2:** Für die Ausführung des Legacy-Core-Projekts erforderlich.

## Interne Abhängigkeiten (Projekt-Referenzen)
- `DJORGA.slnx` referenziert `DJORGA/DJORGA.csproj`.
- `RekordboxAi.csproj` scheint aktuell keine direkten Projekt-Referenzen auf `DJORGA.csproj` zu haben (muss noch validiert werden, da es eine separate Solution-Struktur gibt).
